How an agent pays

Calls a serviceGET /resource
Gets a 402Payment Required + price
SignsA stablecoin authorization from its own wallet — if it’s under the cap
Celo facilitator settlesOn-chain, and it pays the gas
Gets the answerHTTP 200 + receipt with the tx hash

What every agent gets

01

Own wallet

A local-key wallet on Celo mainnet. No API keys.

02

Identity

An ERC-8004 identity registered from the agent wallet.

03

Attribution

An ERC-8021 tag on every transaction the agent sends.

04

x402 buy & sell

Pays 402 endpoints (v1/v2) with a per-payment cap; sells in USA₮ via the Celo facilitator.

Safety & honest status

Guardrails

Every payment is capped ($0.50 by default). A price above the cap is refused before anything is signed. Wallet key files are owner-only (0600).

Not done yet

  • No settled sale as a seller yet (needs a facilitator API key) — no independent payer or repeat counterparty.
  • x402 settlements aren’t tagged.
  • No named end user yet.

Open source

Python framework with Celo mainnet defaults, x402 buyer + seller helpers, ERC-8004 tooling and offline tests. See CELO.md.
